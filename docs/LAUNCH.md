# Как пользоваться сайтом «Бакнин»

## Посетителю

После включения публикации сайт доступен по адресу:
**https://sweaty6.github.io/Baknin_Project/**.
Откройте ссылку в браузере на компьютере или телефоне. Скачивать проект,
устанавливать Python и запускать `app.py` для этого не нужно.

В каталоге найдите вуз поиском или фильтром и откройте его карточку.
В разделе анализа введите русский текст и нажмите кнопку анализа.
Например, фраза «Отличные преподаватели, но общежитие плохое» позволяет
проверить разные оценки тем. Этот технический пример не добавляется в рейтинг.

Анализируют словарные правила в браузере. Введённый текст не отправляется
в Python API и не сохраняется как отзыв. Такой результат требует проверки человеком:
правила не всегда понимают сарказм, контекст и сложные отрицания.

Реальных отзывов в комплекте нет. «Недостаточно данных» в каталоге и карточках
означает отсутствие подтверждённой выборки, а не неисправность сайта.
После добавления разрешённых проверенных данных появятся отзывы и агрегаты.

## Владельцу сайта

Для публикации используйте **[пошаговую инструкцию GitHub Pages](GITHUB_PAGES.md)**.
Вы включаете Pages в настройках репозитория и запускаете процесс **Publish GitHub Pages**.
Сайт собирается на GitHub; устанавливать инструменты на свой компьютер не требуется.

Если ссылка возвращает 404, проверьте включение Pages и успешное завершение
публикации. Адрес обязательно содержит `/Baknin_Project/`.
Инструкция также объясняет ошибки Actions, обновление данных и резервную публикацию
с ветки `gh-pages`.

## Администратору данных и исследователю

Если нужны локальная SQLite, импорт, аудит отзывов или обучение Python-модели,
используйте отдельную инструкцию **[LOCAL_TOOLS.md](LOCAL_TOOLS.md)**.
Эти действия относятся к дополнительным инструментам. Локальная база не
синхронизируется с опубликованным сайтом автоматически, а Python-модель на Pages
не запускается.
