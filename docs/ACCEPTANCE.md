# Проверка сайта и дополнительных инструментов

Проверено 14 октября 2026 года. Основной продукт собирается Node.js и работает
как статический сайт. Python-инструменты проверены отдельно.

## Основной сайт

- `npm ci --ignore-scripts` — установка по зафиксированному `package-lock.json`.
- `npm test` — **48 тестов прошли**, без пропусков. Проверены сборка всех страниц,
  префиксы URL, публичные поля и даты, скрытые тексты, дубли источников, три класса,
  приватные входные данные и сохранение предыдущей сборки при ошибках записи.
- `npm run build -- --output _site --base-path /Baknin_Project/` — созданы
  **11 HTML-страниц**, CSS, JavaScript и публичный снимок со справочником пяти вузов.
  Python, Flask и SQLite в процессе сборки не используются.
- `npm audit --omit=dev` — известных уязвимостей npm-зависимостей не обнаружено.
- Chromium — поиск, переходы в карточки, анализ смешанного русского отзыва,
  отзывы, методика и публикация работают; запросов к Python API нет.
- Мобильные страницы проверены на экране 390 px, инструкция публикации также
  проверена при 320–1440 px: ошибок JavaScript и горизонтального переполнения нет.
- На сайте нет инструкций установки Python для посетителя. `/launch` объясняет
  публикацию на GitHub Pages через интерфейс GitHub.

## Отдельные Python-инструменты

- `python -m pytest -q` — **136 тестов прошли**, без пропусков: API, NLP,
  обучение, контроль артефактов, импорт, аудит, приватные тексты и агрегаты.
- `python -m pip check` — несовместимых зависимостей нет.
- `PYTHONTZPATH='' python -m pytest tests/test_data.py -q` — 36 тестов прошли;
  подтверждён пакетный fallback часовых поясов для систем без IANA-базы, включая Windows.
- Тональность, темы, цитаты и слова браузерной реализации сопоставлены с Python.
  Обе версии читают один словарь `website/data/rules.json`.
- Исправлены повторный URL с изменённым текстом, присвоение одной публикации
  разным вузам, переименование площадки и конфликтующие параллельные импорты.
- Даты фильтров и месячная динамика используют `Europe/Moscow`, как отображение.

## Данные и качество

В комплекте пять вузов и **0 реальных отзывов**. Искусственные технические
фикстуры используются только во временных тестовых каталогах, не публикуются.
Это готовый веб-сайт, который пока не содержит содержательного рейтинга.
Словарный анализ не является обученной ML-моделью; качество на реальном корпусе
не измерено. Параметры рейтинга опубликованы как пилотные и требуют калибровки.
Количество пройденных технических тестов не доказывает точность NLP.

## Публикация

Локальная проверка статических файлов не подтверждает размещение в интернете.
Владелец должен включить Pages в Settings → Pages, Source: GitHub Actions.
Готовая сборка загружается отдельным заданием перед этапом публикации;
ошибка Configure Pages не отменяет проверку самой сборки.
Состояние публичного адреса проверяется после успешного Deploy website.
Подробная инструкция: [GITHUB_PAGES.md](GITHUB_PAGES.md).

Старый большой `project.zip` не был доступен для извлечения из-за ограничения
32 МБ; совместимость с его исходниками не заявляется. Windows-команды дополнительных
инструментов не выполнялись на Windows. Сбор и экспертная разметка корпуса,
курсовая, презентация и проверка доступности всех официальных сайтов остаются
отдельными задачами проекта.
