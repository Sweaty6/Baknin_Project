# Проверка реализации по ТЗ

Проверено 13 октября 2026 года на Linux, Python 3.12.14.

## Выполнено

- `python -m pytest -q`: **121 passed**, без пропусков. Проверены API, русская
  предобработка, отрицания, смешанные аспекты, обучение и контроль артефактов,
  импорт, транзакционный откат, дедупликация, ручной аудит, фильтры и формулы.
- `python -m pip check`: несовместимых зависимостей не обнаружено.
- `node --check static/app.js`: синтаксис JavaScript корректен.
- Реальный запуск через Waitress, `GET /health` и `POST /predict`.
- Chromium: каталог пяти вузов, поиск, живой смешанный анализ, все пять страниц
  на экране 390 px без горизонтального переполнения и ошибок JavaScript.
- Отдельная временная тестовая БД: распределение P/N/U, подтверждённые стороны,
  фильтр отзывов, скрытие запрещённого текста и методика. Искусственные фикстуры
  удалены вместе с временным каталогом; рабочая база содержит **0 отзывов**.
- Повторная инициализация локальной базы не добавляет отзывы и не дублирует вузы.
- GitHub Pages: проверены ссылки с префиксом `/Baknin_Project/`, все страницы,
  поиск, локальный браузерный анализ без запросов к Python API и мобильный экран.
  Отдельные тесты подтверждают совпадение браузерных правил с Python, отсутствие
  закрытых текстов в публичном снимке и защиту исходников/БД при сборке.

Проверка локальной статической сборки не подтверждает её размещение в интернете.
GitHub Pages активируется в Settings → Pages; публичный адрес проверяется отдельно.

## Соответствие программной части

| Требование | Реализация |
|---|---|
| Русский отзыв и отрицания | Одна нормализация обучения и прогнозирования |
| Три класса | Правила и отдельный обучаемый TF-IDF + LogisticRegression |
| Семь тем, разные оценки в одном отзыве | Отдельные аспекты и точные цитаты |
| Прозрачный рейтинг | P/N/U, доля, сглаживание, опубликованные параметры |
| Малая выборка | Нет места и сглаженной оценки; наблюдаемая доля показана с ограничениями |
| База и проверяемые источники | SQLite, JSONL, ссылки и даты, флаги доступа, аудит |
| Метрики | Trainer создаёт macro-F1, per-class report, confusion matrix и baseline |
| Русский адаптивный сайт | Каталог, карточка, отзывы, анализ, методика |
| Запуск на другом компьютере | requirements, README, Linux/PowerShell команды |

## Открытые ограничения

Это готовая программная основа, **не содержательный рейтинг реальных отзывов**.
Корпус не предоставлен; производственная ML-модель не обучена и её качество
не измерено. Стартовый словарный режим требует ручной проверки. Параметры
рейтинга и порог требуют калибровки на корпусе. Число пройденных технических
тестов не заменяет метрики на реальных студенческих отзывах.

Старый `project.zip` не был извлечён: он превышает ограничение передачи файла
32 МБ. Поэтому перенос и совместимость его исходников не подтверждены;
эта версия реализует программную часть ТЗ с нуля. Для сравнения с прежним
кодом нужен архив исходников без встроенного `venv`, IMDb и крупных моделей.

Доступность официальных сайтов вузов не подтверждена из этой среды; справочник
требует проверки перед содержательной публикацией. Windows-команды приведены,
но не выполнялись на Windows. GitHub Actions настроен на Python 3.11/3.12;
его удалённые результаты следует читать в Actions после запуска.
Курсовая, презентация, сбор легального корпуса и экспертная разметка не выполнены.
