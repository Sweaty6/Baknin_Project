# Бакнин — отзывы об аграрных вузах

Русскоязычный сайт: каталог аграрных вузов, карточки вузов, отзывы с источниками,
прозрачный рейтинг, анализ текста и открытая методика. Основной способ использования —
открыть опубликованный сайт в браузере; устанавливать программу на компьютер не нужно.

**Открыть сайт:**
[https://sweaty6.github.io/Baknin_Project/](https://sweaty6.github.io/Baknin_Project/).
Доступность проверена 14 октября 2026 года. Сейчас сайт опубликован из `gh-pages`;
для автоматического обновления из `main` настройте GitHub Actions по инструкции.

**[Подробно: как опубликовать сайт на GitHub Pages](docs/GITHUB_PAGES.md).**
Весь основной процесс выполняется на сайте GitHub, без установки Python или Node.js.

## Публикация за несколько шагов

1. В [Settings → Pages](https://github.com/Sweaty6/Baknin_Project/settings/pages)
   в разделе **Build and deployment** выберите **Source: GitHub Actions**.
2. В **Settings → Environments → github-pages** разрешите ветку `main`
   в **Deployment branches and tags**, если раньше была разрешена только `gh-pages`.
3. Откройте [Actions](https://github.com/Sweaty6/Baknin_Project/actions),
   выберите **Publish GitHub Pages**, нажмите **Run workflow**, выберите `main`
   и подтвердите запуск.
4. Дождитесь зелёного результата. Откройте адрес сайта, показанный в
   **Settings → Pages** или в результате публикации.

Последующие изменения `main` автоматически собирают и публикуют новую версию.
Если публикация не прошла, используйте раздел
[«Если что-то не работает»](docs/GITHUB_PAGES.md#если-что-то-не-работает).

## Что работает на сайте

- Каталог пяти вузов, поиск, фильтры и карточки.
- Раздел отзывов, рейтинг и агрегаты по опубликованным проверенным данным.
- Анализ русского текста: отрицания, три класса тональности и семь тем;
  разные темы смешанного отзыва могут получать разные оценки.
- Методика с объяснением формул и ограничений.
- Адаптивные страницы для компьютера и телефона.

Анализ выполняется словарными правилами прямо в браузере. Введённый текст
не отправляется в Python API и не попадает в отзывы. Обученная ML-модель
на GitHub Pages не запускается; точность правил на реальном корпусе пока не измерена.

**Данные:** есть справочник пяти вузов, реальных отзывов в комплекте нет.
Поэтому сайт показывает «Недостаточно данных». Придуманные отзывы и места
в рейтинге не используются. Инструкции по обновлению:
[каталог и публичные отзывы](docs/GITHUB_PAGES.md#обновить-каталог-и-отзывы).

## Разработчику

Страницы сайта лежат в `templates/`, оформление и браузерный код — в `static/`,
публичные данные и общий словарь — в `website/data/`.
Сборщик `scripts/build_website.mjs` работает на Node.js без установки Python-пакетов.
GitHub автоматически выполняет его процессом
[`.github/workflows/pages.yml`](.github/workflows/pages.yml).

Локальная сборка из корня проекта при установленном Node.js 20 или новее:

```bash
npm ci
npm run build -- --base-path /Baknin_Project/
npm run preview
```

Папка `_site` содержит готовые статические файлы. Локальный адрес —
`http://127.0.0.1:8080/Baknin_Project/`; остановка просмотра — Ctrl+C.
Подробности сборки и резервный способ публикации описаны в
[инструкции GitHub Pages](docs/GITHUB_PAGES.md).
