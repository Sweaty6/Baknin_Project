Запуск на вашем компьютере

Сайт можно открыть онлайн или запустить полную версию с базой данных и Python на своём компьютере.

1. Скачайте проект и установите Python

Установите Python 3.11 или 3.12 (64-бит). В установщике Windows отметьте «Add Python to PATH». Скачайте репозиторий кнопкой Code → Download ZIP и распакуйте его.

Скачать проект →

2. Откройте PowerShell в папке проекта

В этой папке должны находиться app.py и requirements.txt. Введите команды по очереди:

py -3.11 -m venv .venv
.\.venv\Scripts\python.exe -m pip install -r requirements.txt
.\.venv\Scripts\python.exe -m baknin.cli init
.\.venv\Scripts\python.exe app.py

Если у вас Python 3.12, замените первую команду на py -3.12 -m venv .venv. Дождитесь окончания установки пакетов.

3. Откройте сайт

Введите в браузере http://127.0.0.1:5000. Оставьте окно PowerShell открытым. Для остановки нажмите Ctrl+C. При следующем запуске достаточно последней команды.

При первой установке сайт содержит справочник пяти вузов. Реальные отзывы нужно импортировать отдельно; обученная ML-модель не входит в комплект. Словарный анализ работает сразу, но требует проверки.

Онлайн-версия и полная версия

GitHub Pages показывает каталог и опубликованные данные, а словарный анализ выполняет в браузере. Вводимый текст не отправляется на сервер анализа. Импорт, ручной аудит SQLite и обучение доступны в полной Python-версии.
