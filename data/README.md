# Данные

`universities.json` — пилотный справочник аграрных вузов. Отзывы в комплект не входят.
Все результаты, показанные после импорта, должны иметь разрешённые первоисточники.

Для `python -m baknin.cli import --input файл.jsonl` каждый объект содержит:

| Поле | Требование |
|---|---|
| `university_id` | Строковый ID из `universities.json` |
| `text` | Непустой текст, максимум 5000 символов |
| `source` | `{platform, url, terms_checked_at}`; URL HTTPS, дата ISO 8601 |
| `source_url` | HTTPS-ссылка именно на исходный отзыв |
| `source_review_id` | Необязательный стабильный ID записи на исходной площадке |
| `published_at` | Дата публикации ISO 8601 |
| `collected_at` | Дата сбора ISO 8601 |
| `verified` | `true` после ручной проверки происхождения и принадлежности вузу |
| `personal_data_removed` | `true` после очистки ненужных персональных данных |
| `display_allowed` | Можно ли показывать текст/фрагмент на сайте |
| `original_score` | Необязательная исходная оценка автора |
| `sentiment` | Необязательная ручная метка `positive`, `negative`, `neutral` |
| `aspects` | Необязательные проверенные `[{aspect,sentiment,context}]`, только вместе с ручной общей меткой |

Если `display_allowed=false`, текст хранится локально при наличии права хранения,
но не отдаётся публичным API. Право хранения нужно проверять отдельно; одного
флага недостаточно. Импортёр не загружает страницы и не проверяет юридические
условия. Не переносите базу с приватными текстами в публичный репозиторий.

Импорт проверяется целиком до записи; неверная строка отменяет весь файл.
Нормализованные дубли в пределах вуза не увеличивают выборку. Одинаковый текст
для разных вузов нужно дополнительно проверить вручную: это возможный спам.
Источник, дата, исходный текст и аудиторские решения сохраняются в SQLite.
Общая ручная метка не подтверждает аспекты автоматически; гипотезы правил
показываются отдельно и не участвуют в сильных/слабых сторонах до проверки.

Не создавайте искусственные отзывы для заполнения рейтинга. Технические примеры
для тестов допустимы только во временной БД и с явной отметкой об их назначении.
